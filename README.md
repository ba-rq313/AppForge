# AppForge

**نسخة أولية عربية لتخصيص مشاريع Android Gradle التي تملك حق تعديلها.**

> رابط Google Play لا يحتوي الشيفرة المصدرية أو ملف APK الأصلي بالضرورة. لا يقوم AppForge بتنزيل ملفات التطبيقات التجارية أو فكّها أو تجاوز تراخيصها. وهو لا يحذف إعلانات تطبيقات الآخرين تلقائيًا.

## الميزات

- واجهة ويب عربية RTL متجاوبة.
- يتحقق من رابط صفحة Google Play الرسمية ويستخرج package ID؛ يحاول جلب الاسم والوصف العامين إذا سمحت صفحة المتجر.
- يقبل ZIP لمشروع Android Gradle المصدر، ثم يعدّل اسم التطبيق ومعرّف التثبيت `applicationId` عندما تكون إعدادات المشروع واضحة.
- يمكنه توليد أحجام أيقونة launcher الأساسية من صورة يرفعها المستخدم.
- ينزّل مشروع المصدر المعدّل داخل ZIP لتراجعه وتبنيه في Android Studio أو باستخدام Gradle.
- حماية أساسية من Zip Slip والروابط الرمزية والأرشيفات التي يتجاوز حجمها بعد الفك 250 MB.
- اختبارات آلية عبر pytest وGitHub Actions.

## التشغيل محليًا

يتطلب Python 3.10 أو أحدث (يوصى بـ 3.12).

```bash
python -m venv .venv
source .venv/bin/activate     # Linux / Chromebook Linux
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`. توثيق API متاح على `http://127.0.0.1:8000/api/docs`.

إذا ظهرت رسالة `externally-managed-environment`، لا تثبّت الحزم على Python الخاص بالنظام؛ أنشئ بيئة افتراضية كما في الأوامر أعلاه.

## التشغيل باستخدام Docker

```bash
docker build -t appforge .
docker run --rm -p 8000:8000 appforge
```

## رفعه إلى GitHub

1. أنشئ مستودعًا جديدًا باسم `AppForge` على GitHub.
2. فكّ ملف ZIP الذي حصلت عليه من هذا المشروع.
3. من داخل المجلد شغّل:

```bash
git init
git add .
git commit -m "Initial AppForge project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/AppForge.git
git push -u origin main
```

استبدل `YOUR-USERNAME` باسم حساب GitHub الخاص بك. لا تضع مفاتيح أو رموز وصول داخل المستودع.

## حدود التخصيص

- يجب رفع **مشروع المصدر كاملًا**، لا رابط المتجر فقط ولا ملف APK منفردًا.
- هذه النسخة لا تضمن بناء كل المشاريع؛ فمشاريع Kotlin/Gradle تختلف في البنية، وقد تحتاج تعديلات يدوية أو إعدادات محلية.
- تُغيّر الأداة `applicationId` عند وجود إعداد Gradle مناسب، وتُبقي `namespace` وحزم Kotlin/Java كما هي لتقليل احتمال كسر المشروع. لذلك قد تحتاج بعض المشاريع إلى تعديلات إضافية.
- يمكن استبدال أيقونات launcher bitmap الشائعة؛ لا تضمن الأداة اكتشاف كل نظام أيقونات مخصص.
- لا تُعد الأداة شهادة بأن المصدر آمن أو خالٍ من الشيفرات الضارة. راجع المصدر قبل البناء.
- إزالة الإعلانات من تطبيق تملكه تكون بتعديل تكاملات الإعلانات في شيفرتك المصدرية، بعد التأكد من الالتزامات القانونية والتعاقدية.
